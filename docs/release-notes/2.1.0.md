# StudySynth 2.1.0

A faster, friendlier StudySynth with automatic updates.

## What's new

- **New home screen** — pick up where you left off, start practice, or jump into a timed test in one tap.
- **Three clear destinations** — Home, Library and Progress, always within thumb reach at the bottom of the screen.
- **Cleaner library** — each set shows its title, question count and your last score. Long topic blurbs, exam codes and other filler are gone.
- **Update Centre** — see the installed version, check for updates, read release notes and choose how updates are delivered.
- **Automatic web updates** — interface improvements arrive without reinstalling the app. An update never interrupts a mock test.
- **Content updates** — question banks and explanations can be updated separately from the app, and the previous set is kept so a bad update can be rolled back.
- **Verified downloads** — every app, web and content update is signed and checksummed before it is used. Tampered files are rejected.

## Under the hood

- Question engine, answer keys, explanations, bookmarks, attempts and revision history are unchanged. Your data is preserved.
- The library still opens offline, with all 20 bundled sets and 8,519 questions available without a network.

## Notes

- The app keeps the same application ID and signing identity as 2.0.0, so it installs over your existing copy.
- Android always shows its own installer for app updates; StudySynth cannot install silently, by design.
