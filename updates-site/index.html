StudySynth update channel

This site hosts signed update artifacts for the StudySynth Android app. Nothing here is meant to be opened in a browser.

  • Stable manifest — the signed release description the app reads.
  • updates/stable/apk/ — signed application packages.
  • updates/stable/web/ — signed OTA web bundles.
  • updates/stable/content/ — signed educational content packages.

Every artifact is verified by the installed app before it is used. A tampered file is rejected.
